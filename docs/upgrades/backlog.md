# Upgrade backlog

This backlog is intentionally small and evidence-oriented. Run `./scripts/project suggest-upgrades` before adding a new item.

| State | Upgrade | Evidence needed | Owner | Recheck |
| --- | --- | --- | --- | --- |
| candidate | Replace starter placeholders | `./scripts/project doctor --json` | project owner | before first feature |
| candidate | Add project-specific quality commands | clean checkout run from `docs/project-commands.md` | project owner | before release |
| candidate | Recheck external agent/project research | `./scripts/project research <slug> <question>` | maintainer | monthly or on tool change |

Do not delete rejected ideas; archive them with the reason and evidence so future agents do not rediscover the same dead end.
