# Lavish presentations

The committed `.lavish/project-starter-operating-system.html` is a reviewable visual overview of this starter's memory, research, upgrade, specialist, and security loops.

The `.lavish/repo-walkthrough.html` report maps the repository workflow and records the resolution of the six gaps identified in the 2026-11-08 walkthrough.

Open either review surface with `lavish-axi`:

```bash
lavish-axi .lavish/project-starter-operating-system.html
lavish-axi .lavish/repo-walkthrough.html
```

Open it locally with:

```bash
npx -y lavish-axi .lavish/project-starter-operating-system.html
```

All pages share `.lavish/theme.css` and `.lavish/theme.js` (Auto, Light, Dark). `.lavish/theme-preview.html` shows every component in both appearances; `DESIGN.md` records the rules. Design work goes through the `impeccable` skill.

Keep presentation claims linked to repository files. The HTML is a communication artifact, not a second source of truth. Create future presentations under `.lavish/` and register their purpose here.
