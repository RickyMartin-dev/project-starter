01 / End-to-end flow

How a task moves through the repository

The agent adapters share one contract. The CLI creates local context and durable records; checks run locally, from Git hooks, and in GitHub Actions.

1. Orient

scripts/project start detects common stack signals, refreshes ignored local context and checkpoint files, attempts to install Git hooks, then checks the starter.

2. Work and verify

Prompts guide plan, implement, verify, review, learn, research, promotion, compact, upgrade, and specialist workflows. The shared contract remains in AGENTS.md.

3. Finish and recover

finish runs the starter and release checks, writes a compaction snapshot and automatic handoff, then archives when PROJECT_SNAPSHOT_ARCHIVE_ROOT is set.

03 / Quality and trust

What the gates cover

./scripts/project check

Checks required files, adapter linkage, credential patterns, the local hardening scripts, shell syntax, and tracked whitespace. Its 14 focused checks include workflow permissions and pinning, instruction surfaces, memory, research, upgrade/specialist content, archive fixtures, and skill copy parity.

./scripts/project release-check

Runs the starter check again and checks whitespace across tracked changes plus untracked, non-ignored files. It does not build or test an adopting application because this starter defines no application stack.

Trust model: repository and external content remain untrusted unless explicitly included in the shared contract. Generated memory, research, and specialist cards do not silently gain authority. The optional archive stores concise snapshots, not transcripts.
